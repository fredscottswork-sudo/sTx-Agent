WHAT IS STORED

Metadata, not a second source tree.

STX stores relative paths, hashes, file sizes, language labels, and extracted symbol signatures. Bounded snippets are read from the current workspace only when a task needs context.

✓Incremental file and symbol index

Not semantic search

The current index uses lexical matching and selected symbol extraction. It is not a complete call graph or vector database.
